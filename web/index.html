Guess the Number

I am thinking of a number between 1 and 100. Can you find it?

Attempts 0
Possible range 1 – 100
Best score –

i Ready when you are. Type a number and hit Guess.

    Rules of the game
    1. The server picks a secret number between 1 and 100.
    2. Type a guess and press Enter or click Guess.
    3. You get a hint: too small, or too large.
    4. Only valid guesses count as attempts, so typing letters or numbers like 250 costs nothing.
    5. Find the number in as few attempts as possible and beat your best score.

    The secret number stays in the Java backend — no peeking in the browser!
